# Имена клиентов в журнале

Журнал показывает текущие имена устройств из Keenetic рядом с исходными IP. Фильтр «Клиент» объединяет известные IPv4 и IPv6 одного устройства. Поиск также находит имена устройств.

Список устройств и IPv6-соседи читаются только при открытии или ручном обновлении журнала. Постоянного опроса и отдельного демона нет. Если Keenetic не отдаёт данные или адрес неоднозначен, остаётся IP; чтение журнала продолжает работать. Исходный текст журнала сохраняется без изменений.

Имена соответствуют текущему состоянию сети. Для старых записей после смены владельца IP это не доказательство исторической принадлежности адреса. Устройства с собственным зашифрованным DNS в обход SmartDNS в этом журнале не появляются.
