# SmartDNS WebUI для Entware 🚀

Легковесный, быстрый и современный веб-интерфейс (SPA) для управления конфигурацией SmartDNS на роутерах с установленным Entware (Keenetic, Asus и др.).

## Особенности
- **Два режима:** Удобный визуальный интерфейс и "Сырой" (Raw) редактор конфига.
- **SPA Архитектура:** Мгновенное переключение вкладок без перезагрузки страницы (Vanilla JS).
- **Управление списками:** Создание, редактирование и удаление `.list` файлов маршрутизации.
- **Просмотр логов:** Чтение логов сервиса прямо из браузера.
- **Автообновление:** Уведомление о новых версиях и обновление в один клик.
- **Нулевые зависимости:** Написан на чистом Shell (sh), не требует PHP, Python или Node.js.

## Установка (Одной командой)
Подключитесь к роутеру по SSH и выполните команду:
```bash
curl -sL [https://raw.githubusercontent.com/YOUR_USERNAME/smartdns-webui/main/install.sh](https://raw.githubusercontent.com/YOUR_USERNAME/smartdns-webui/main/install.sh) | sh
```

После установки интерфейс будет доступен по адресу: http://<IP_РОУТЕРА>:3000 (например, http://192.168.1.1:3000).

## Системные требования
- Entware
- lighttpd (в качестве веб-сервера)
- curl
