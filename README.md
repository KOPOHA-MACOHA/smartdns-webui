# SmartDNS WebUI

Веб-панель для визуального редактирования конфигурации SmartDNS на Keenetic/Entware. Работает через `lighttpd` и shell CGI, без отдельного Node.js/PHP-сервера.

## Возможности

- Визуальное редактирование основных параметров, DNS-серверов, DNS-групп и маршрутизации.
- Светлая и тёмная темы интерфейса.
- Raw-режим для прямого редактирования исходного конфига.
- Создание и редактирование доменных списков `.list`.
- Просмотр и очистка доступного панели журнала SmartDNS.
- Статическая проверка части распространённых ошибок перед сохранением. Она не заменяет нативную проверку конфигурации SmartDNS.
- Ручной «Тест DNS» отдельным ограниченным экземпляром 46.1 без применения
  конфига: UDP/TCP, используемые группы и маршруты. [Режим и ограничения](docs/PREFLIGHT.md).
- Тестовый режим UI и проверка доступных обновлений.

Визуальный редактор не покрывает все директивы SmartDNS. Для неизвестных параметров используйте Raw-режим и сохраняйте резервную копию.

## Требования

- Entware и работающий `lighttpd`.
- Установленный SmartDNS с конфигом `/opt/etc/smartdns/smartdns.conf`.
- `curl`, `sh` и стандартные утилиты Entware/BusyBox.
- Свободный TCP-порт 3000.

Bootstrap-стили, иконки, CodeMirror и SortableJS загружаются с CDN, поэтому браузеру нужен доступ к этим ресурсам.

## Установка

Перед установкой сохраните конфигурацию SmartDNS и убедитесь, что порт 3000 не занят. Скачайте установщик, просмотрите его и только затем запускайте:

```sh
curl -fsSL https://raw.githubusercontent.com/KOPOHA-MACOHA/smartdns-webui/main/install.sh -o /opt/tmp/smartdns-webui-install.sh
less /opt/tmp/smartdns-webui-install.sh
sh /opt/tmp/smartdns-webui-install.sh
```

Если `less` не установлен, просмотрите файл командой `cat`. После установки откройте `http://<LAN-IP>:3000`, подставив LAN-IP роутера.

Установщик создаёт резервные копии заменяемых файлов приложения и конфигурации `lighttpd` в `/opt/var/backups/smartdns-webui/`. Это не заменяет отдельную копию `/opt/etc/smartdns/smartdns.conf` и каталога `/opt/etc/smartdns/domains/`.

## Использование

Сборка 1.4.0 добавляет [применение с независимым откатом](docs/SAFE-APPLY.md).
По умолчанию оно отключено сервером до отдельной приёмки; на роутере владельца
реальный рестарт и автоматический откат проверены 2026-10-23, функция включена.

- **Настройки:** визуальный режим для поддерживаемых директив, Raw для полного текста.
- **Списки:** создание, редактирование и удаление файлов в `/opt/etc/smartdns/domains/`.
- **Логи:** показывает `/opt/var/log/smartdns/smartdns.log`, если файл доступен панели.
- **Тест-режим:** направляет операции панели во временные пути под `/opt/tmp` и имитирует перезапуск. Это не полноценная песочница и не замена резервной копии.
- **Обновление:** кнопка версии проверяет `version.txt` в `main` и запускает обновление при наличии более новой версии. Журнал обновления: `/opt/var/log/smartdns-webui-update.log`.

Сохранение конфигурации и перезапуск SmartDNS - разные действия. После сохранения проверьте конфиг перед применением.

## Безопасность

- Авторизация использует логин `root` и текущий пароль Entware; отдельный пароль панели не создаётся.
- Не публикуйте порт 3000 в интернет. HTTP Basic Auth не шифрует пароль при передаче. Используйте доверенную LAN или VPN.
- Перед обновлением или важными изменениями сохраняйте резервную копию конфигурации SmartDNS и списков.

## Удаление

1. Сохраните копию `/opt/etc/lighttpd/conf.d/90-smartdns.conf`.
2. Удалите или переместите этот файл и проверьте конфигурацию `lighttpd`.
3. После отключения endpoint панели можно удалить `/opt/share/www/smartdns/` и при необходимости резервные копии.
4. Не удаляйте конфигурацию SmartDNS и доменные списки, если продолжаете пользоваться SmartDNS.

## Разработка

Изменения вносите в отдельную ветку и проверяйте через Pull Request. Совместимость зависит от версии Entware, `lighttpd` и SmartDNS.

Локальные регрессионные тесты (Node.js 22):

```sh
npm ci
npm test
```

Зависимости npm нужны только для тестов на компьютере и в CI; установщик не
копирует их на роутер. DOM-тесты проверяют чтение, редактирование и сохранение
директив, включая несколько DNS-групп, адресов и привязок `bind`.

В импортированных серверных строках визуальный редактор сохраняет параметры
`-group`, `-exclude-default-group` и `-bootstrap-dns`. Для новой строки без
явной группы редактор добавляет группу выбранной карточки. Группа с именем
`fallback` сама по себе не включает автоматический резерв.
